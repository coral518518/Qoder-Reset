# Qoder 重置工具 🔒

一款专为 Qoder AI IDE 设计的本地隐私与身份重置工具。支持现代版 Qoder（v0.4.x+，数据目录 `com.qoder.app.stable` 与 `~/.qoder`）及早期版本。提供直观的图形用户界面（GUI）与完整的命令行（CLI）控制台模式。

---

## ✨ 核心功能

### 🚀 主要特性
- **全面适配最新 Qoder**：自动识别现代 Qoder 数据目录（`com.qoder.app.stable`）、用户代理主目录（`~/.qoder`）以及旧版安装路径。
- **一键全量重置**：快速刷新所有应用标识、清除遥测数据与本地登录态。
- **机器标识与指纹刷新**：同步重置现代 `auth.machine-id`、旧版 `machineid`、插件级 `machine_id`、独立安装标识 `installation_id`，并清理硬件令牌缓存。
- **深度 SQLite 与存储清理**：安全清空 `main.sqlite` 中的会话表、账号凭证、设备标识，并自动维护 FTS5 全文索引，杜绝检索报错。
- **Chromium 网络与会话抹除**：彻底清除 Cookies、Trust Tokens、网络状态记录、LevelDB 本地持久化存储与离线遥测队列。
- **身份备份与一键恢复**：每次重置前自动创建带时间戳的完整身份备份，随时可安全回滚。
- **全功能无头 CLI 模式**：在无图形界面的环境或轻量控制台中直接通过命令行参数完成所有操作。

### 🔐 隐私与安全保障
- **纯本地数据操作**：工具仅操作 Qoder 自身的数据文件与缓存，绝不修改操作系统配置、注册表或硬件固件。
- **安全白名单机制**：绝不触碰用户工程源码项目文件，防止误删代码。
- **对话记录可选保留**：提供勾选项，支持在重置设备身份的同时保留对话与历史记录。

## 📋 环境与依赖要求

### 环境要求
- **操作系统**：Windows 10/11 (x64)、macOS 10.14+、Linux
- **Python 版本**：Python 3.7 及以上

### 可选依赖
- `PyQt5` 或 `PyQt6` 或 `PySide6`（图形界面运行所需）
- `requests`

> **提示**：如果系统中未安装 Qt 图形库，程序会自动平滑降级为命令行控制台模式（CLI）运行，功能完全不受影响。

## 📖 使用指南

### 1. 图形界面模式（推荐）

#### Windows 用户：
直接双击运行目录下的 **`start_gui.bat`** 即可自动检测环境并启动。

#### 命令行启动 GUI：
```bash
python qoder_reset_gui.py
```

#### 界面操作流程：
1. **一键修改配置**：点击“一键修改配置”按钮，程序将自动终止 Qoder 进程、备份现有身份，并完成全套数据与机器码重置。
2. **保留对话记录**：勾选“保留对话记录”复选框后再重置，将保留历史聊天数据；取消勾选则进行彻底干净清理。
3. **备份与恢复**：
   - 点击“备份身份数据”：手动生成当前身份的快照备份。
   - 点击“恢复身份数据”：从历史备份中选择并恢复之前的身份数据。
4. **单项高级操作**：支持单独点击“关闭 Qoder”、“重置机器 ID”、“重置遥测数据”、“清理登录身份”、“深度身份清理”。

---

### 2. 命令行控制台模式（CLI）

在终端中可直接通过参数运行，无需打开图形窗口：

```bash
# 查看帮助文档与支持参数
python qoder_reset_gui.py --help

# 查看当前 Qoder 运行状态、安装目录与当前机器 ID
python qoder_reset_gui.py --status

# 一键执行完整重置（默认保留对话记录）
python qoder_reset_gui.py --reset

# 一键彻底干净重置（不保留对话记录）
python qoder_reset_gui.py --reset --no-preserve-chat

# 手动创建当前身份备份
python qoder_reset_gui.py --backup

# 列出所有可用的历史备份
python qoder_reset_gui.py --list-backups

# 从最近一次备份恢复身份
python qoder_reset_gui.py --restore latest

# 终止正在运行的 Qoder 相关进程
python qoder_reset_gui.py --close-qoder
```

## ❓ 常见问题排查

### 1. 运行 `start_gui.bat` 提示缺少 PyQt5？
启动脚本会自动尝试为您安装 `PyQt5` 或 `PyQt6`。如果网络环境受限无法安装，程序会自动切换到控制台 CLI 模式运行，不会崩溃。

### 2. 重置后提示“FTS5 格式错误”？
最新版工具内置了 FTS5 虚拟索引自动自愈机制，已完全解决该问题。无论执行重置还是启动程序，都会自动维护 SQLite 全文索引结构完整。

### 3. 重置后是否会丢失我的项目代码？
**绝对不会。** 本工具只重置 Qoder 应用本体的缓存、遥测与账号会话数据，绝不扫描或修改您保存在电脑中的代码仓库与工作区源码。
